## ขั้นที่ 1 · สร้างโปรเจกต์ Supabase ใหม่
1. เข้า https://supabase.com/dashboard แล้วกด **New project**
2. ตั้งชื่อ `SmartTable` · Region เลือก **Southeast Asia (Singapore)**
3. ตั้ง Database Password แล้ว**จดเก็บไว้** (ต้องใช้ตอนย้ายข้อมูล)
4. กด Create แล้วรอ 1–2 นาที

## ขั้นที่ 2 · รัน SQL
1. เมนูซ้าย **SQL Editor** → **New query**
2. เปิดไฟล์ `sql/st-01-auth.sql` ด้วย Notepad → กด `Ctrl+A` แล้ว `Ctrl+C`
3. วางในช่อง SQL (`Ctrl+V`) แล้วกด **Run**
4. ต้องขึ้น `Success. No rows returned` (ถ้าเห็นคำเตือนสีเหลือง เช่น "already exists, skipping" ไม่เป็นไร)
5. ตรวจ: เมนู **Table Editor** ต้องเห็นตาราง `st_profiles` และ `st_schema_log` (ห้ามสร้างหรือแก้ตารางในหน้านี้เอง)

## ขั้นที่ 3 · ใส่ key ในไฟล์ตั้งค่า
1. Supabase → **Project Settings** (รูปเฟือง) → **API Keys** / **Data API**
2. คัดลอก **Project URL** และ **Publishable key** (`sb_publishable_...`) หรือ **anon public** key
3. เปิด `js/st-config.js` ด้วย Notepad แล้ววางแทน `YOUR-...` ทั้ง 2 จุด แล้วบันทึก
4. ⚠️ ห้ามใช้ **service_role / secret** key เด็ดขาด

## ขั้นที่ 4 · ขึ้น GitHub Pages
1. เข้า https://github.com/new → Repository name: `smarttable` → เลือก **Public** → **Create repository**
2. กดลิงก์ **uploading an existing file**
3. เปิดโฟลเดอร์ `smarttable` ใน File Explorer → เลือกทุกอย่างข้างใน (`Ctrl+A`) แล้วลากไปวางในหน้าเว็บ
   (ต้องลากโฟลเดอร์ `css` `js` `sql` ไปด้วย ไม่ใช่ลากโฟลเดอร์ `smarttable` ทั้งก้อน)
4. กด **Commit changes**
5. **Settings** → **Pages** → Source: *Deploy from a branch* → Branch: `main` / `(root)` → **Save**
6. รอ 1–2 นาที เว็บจะอยู่ที่ `https://bossrachun9696-stack.github.io/smarttable/`

## ขั้นที่ 5 · บอก Supabase ว่าเว็บเราอยู่ที่ไหน (สำคัญมาก ไม่งั้นลิงก์ในอีเมลใช้ไม่ได้)
Supabase → **Authentication** → **URL Configuration**
- **Site URL**: `https://bossrachun9696-stack.github.io/smarttable/`
- **Redirect URLs** → Add URL: `https://bossrachun9696-stack.github.io/smarttable/**`
- กด Save

## ขั้นที่ 6 · (ข้ามได้ตอนนี้) เปลี่ยนอีเมลเป็นภาษาไทย
⚠️ โปรเจกต์ฟรีที่สร้างหลัง 3 มิ.ย. 2569 แก้แม่แบบอีเมลไม่ได้ จนกว่าจะตั้ง SMTP ของตัวเอง (เช่น Resend)
และระบบอีเมลในตัวของ Supabase ส่งได้เฉพาะอีเมลของสมาชิกทีมในโปรเจกต์ (ทดสอบด้วยอีเมลตัวเองได้)
เมื่อตั้ง SMTP แล้ว ให้ไปที่ Authentication → **Emails** → แท็บ **Templates**
- **Confirm signup** หัวข้อ: `ยืนยันอีเมลของคุณ` · เนื้อหา:
  ```html
  <h2>ยืนยันอีเมล</h2>
  <p>กดลิงก์ด้านล่างเพื่อยืนยันอีเมลและเริ่มใช้งาน</p>
  <p><a href="{{ .ConfirmationURL }}">ยืนยันอีเมล</a></p>
  ```
- **Reset password** หัวข้อ: `ตั้งรหัสผ่านใหม่` · เนื้อหา:
  ```html
  <h2>ตั้งรหัสผ่านใหม่</h2>
  <p>กดลิงก์ด้านล่างเพื่อตั้งรหัสผ่านใหม่ ถ้าคุณไม่ได้ขอ ไม่ต้องทำอะไร</p>
  <p><a href="{{ .ConfirmationURL }}">ตั้งรหัสผ่านใหม่</a></p>
  ```
  (ไม่ใส่ชื่อแอปในอีเมล เพราะหลังย้ายไปรวมกับ DarkChat จะใช้แม่แบบอีเมลชุดเดียวกัน)

## ขั้นที่ 7 · ทดสอบบน iPhone
1. เปิด Safari ไปที่ลิงก์ GitHub Pages ของคุณ
2. แท็บ **สมัครสมาชิก** → กรอกชื่อ อีเมล รหัสผ่าน → ต้องขึ้นข้อความสีเขียวว่าส่งลิงก์แล้ว
3. เปิดแอป Mail → กดลิงก์ยืนยัน → ต้องเข้าหน้า "สวัสดี ชื่อของคุณ"
4. ลองแก้ชื่อแล้วกดบันทึก → ออกจากระบบ → เข้าสู่ระบบใหม่
5. ลอง **ลืมรหัสผ่าน** → กดลิงก์ในอีเมล → ตั้งรหัสใหม่ → เข้าสู่ระบบด้วยรหัสใหม่
6. Supabase → Table Editor → `st_profiles` ต้องเห็นแถวของคุณพร้อมอีเมล

# ขั้นที่ 3 · เมนูและรูปอาหาร

## A · รัน SQL ไฟล์ที่ 3
1. Supabase → **SQL Editor** → **New query**
2. เปิด `sql/st-03-menu.sql` ด้วย Notepad → `Ctrl+A` → `Ctrl+C` → วาง → **Run** → ต้องขึ้น `Success`
3. ตรวจ: เมนู **Storage** ต้องเห็นถังชื่อ `st-images` (Public) · ห้ามสร้างถังเองด้วยมือ

## B · อัปโหลดไฟล์ขึ้น GitHub
ครั้งนี้ใน zip มี `js/st-config.js` ของคุณอยู่แล้ว **อัปโหลดทับได้ทุกไฟล์**

## C · ทดสอบบน iPhone
1. เข้าร้าน → แตะ **เมนูอาหาร**
2. เพิ่มหมวด เช่น `อาหารจานเดียว` `เครื่องดื่ม` · ลองกด ↑ ↓ สลับลำดับ

5. กด **บันทึกเมนู** → เมนูต้องขึ้นพร้อมรูป · แตะชื่อเมนูเพื่อแก้ไข
6. แตะสวิตช์ด้านขวา → เปลี่ยนเป็น **หมด** (สีเทา) · ลองล็อกอินด้วยบัญชีพนักงานครัว จะกดได้แค่สวิตช์นี้

   (ไม่เปิดก็ใช้งานได้ แค่โต๊ะที่ลืมปิดจะค้างจนกว่าพนักงานกดปิด)

## B · อัปโหลดไฟล์ทั้งหมดใน zip ขึ้น GitHub (ทับได้ทุกไฟล์)

## C · ทดสอบ
1. เข้าร้าน → **โต๊ะและ QR** → ส่วน "เพิ่มหลายโต๊ะพร้อมกัน" ใส่ 1 ถึง 6 → **เพิ่มโต๊ะ**
2. แตะโต๊ะ 1 → **แสดง QR ให้ลูกค้าสแกน** → ใช้มือถืออีกเครื่อง (หรือกล้อง iPhone ส่องจอคอม) สแกน

   - ในรายการเมนู แตะปุ่ม **∞ / เหลือ n** เพื่อตั้งจำนวนเร็ว ๆ (ครัวทำได้ เช่น ตั้งยอดตอนเช้า)
   - ขายครบแล้วขึ้น "หมด" เอง · ยกเลิกออร์เดอร์แล้วคืนจำนวน
   - ลูกค้าเห็นป้าย กรองได้ (เช่น 🥬 มังสวิรัติ, 🚫 ไม่มีถั่ว) และเห็น "เหลือ n" เมื่อเหลือ ≤5
4. **หน้าตาร้าน**: ร้าน → การ์ด **หน้าตาร้าน** → เลือกโลโก้ รูปปก (แนวนอน) และสีร้าน → สแกน QR ดูหน้าลูกค้า
5. **ประวัติการทำงาน**: ร้าน → **🕵️ ประวัติการทำงาน** (เจ้าของ / ผู้จัดการ)
   - สรุปต่อพนักงาน: ยกเลิกออร์เดอร์ ส่วนลด ปิดโต๊ะไม่เก็บเงิน ยกเลิกใบเสร็จ
   - บันทึกเพิ่ม: เปลี่ยนเลขพร้อมเพย์ (สีแดง), เปลี่ยนค่าบริการ/VAT, เปลี่ยนราคา, ย้าย/รวมโต๊ะ, เพิ่ม/เปลี่ยน/นำออกพนักงาน
   - เริ่มบันทึกตั้งแต่รันไฟล์ st-09 (เหตุการณ์ก่อนหน้านั้นไม่มีในประวัติ)

## C · ทดสอบ
1. **หลายภาษา**: ร้าน → การ์ด **หน้าตาร้าน** → ติ๊ก 🇬🇧 English / 🇨🇳 中文
   - เมนูอาหาร → แตะเมนู → ส่วน **🌐 คำแปล** ใส่ชื่อ คำอธิบาย และคำแปลตัวเลือก → บันทึก
   - หมวดหมู่ → ปุ่ม 🌐 ใส่ชื่อหมวดภาษาอื่น
   - สแกน QR → มุมขวาบนมีปุ่ม **ไทย / EN / 中文** (มือถือที่ตั้งภาษาอังกฤษ/จีนจะเลือกให้เอง)
   - ปุ่ม ข้อความ สถานะ ทั้งหน้าเปลี่ยนภาษา · เมนูที่ยังไม่แปลแสดงภาษาไทย · **ครัวเห็นภาษาไทยเสมอ**
2. **โปรตามเวลา**: ร้าน → **🏷 โปรโมชันและคูปอง** → **+ เพิ่มโปร** → ตั้งชื่อ % วัน เวลา และใช้กับ ทั้งเมนู/บางหมวด/บางเมนู
   - ช่วงเวลาโปร ลูกค้าเห็นราคาขีดฆ่า + ราคาใหม่ + ป้าย −20% · ราคาจริงคิดที่เซิร์ฟเวอร์ตามเวลาที่ส่งรายการ
   - ข้ามเที่ยงคืนได้ เช่น 22:00–02:00 · มีหลายโปรพร้อมกัน ระบบใช้โปรที่ลดมากสุด
3. **คูปอง**: หน้าเดียวกัน → **+ เพิ่มคูปอง** → โค้ด (เช่น HELLO10) ลด % หรือบาท ยอดขั้นต่ำ ลดสูงสุด วันหมดอายุ จำนวนครั้ง
   - ตอนเช็กบิล: ใส่โค้ด → **ใช้คูปอง** → ส่วนลดขึ้นให้เอง → รับเงิน (ระบบนับจำนวนครั้งที่ใช้)
4. **ส่วนลดเป็น %**: หน้าเช็กบิล ช่องส่วนลด กดสลับ **฿ / %**
5. **ให้คะแนน**: ลูกค้ากด **ขอเช็กบิล** → การ์ด "มื้อนี้เป็นอย่างไรบ้าง?" ขึ้น → แตะดาว 1–5 + เขียนความเห็น → ส่ง
   - ให้คะแนนได้จนถึง 3 ชั่วโมงหลังจ่ายเงิน (เปิดหน้าเดิมค้างไว้) · แก้คะแนนได้
   - ดูผล: **📊 รายงานยอดขาย** → ส่วน **⭐ คะแนนจากลูกค้า** (คะแนนเฉลี่ย กราฟ 1–5 ดาว ความเห็นล่าสุด)
